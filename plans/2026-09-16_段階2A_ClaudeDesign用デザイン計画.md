対象: `copia-shift-app` 段階2A（I-02 詳細と編集の分離 / I-05 配置と密度 / I-07 共通ダイアログ）

## 0. このアプリは何か（30秒）

小規模チーム（1〜30人）がシフト希望を出し、リーダー・管理者が確定するWebアプリ。日本語のみ、ライトテーマのみ。PC（1280px前後）で全体調整、スマートフォン（375px）で本人の希望入力を行う。

利用者は3種類。

| 役割 | 最初に知りたいこと | 主操作 |
|---|---|---|
| メンバー | 次の自分のシフト、希望の提出状況 | 希望入力 |
| リーダー | 何が未確定か | 確認・確定・差し戻し |
| 管理者 | 上記＋メンバー・設定 | 運用設定 |

## 1. 作ってほしいもの（アートボード一覧）

すべて日本語。氏名は「田村駿貴」「赤間」「曽根」「佐藤」「鈴木」「高橋」など実在しそうな和名で、**2文字と6文字の両方**を混ぜること。

### PC（幅1280px）

1. **P1 シフトを見る（一覧ビュー）** — 縦=メンバー、横=1か月の日付。右に詳細パネル。
2. **P2 シフトを見る（月ビュー）** — 7列カレンダー。
3. **P3 シフトを見る（週ビュー）** — 7日ぶんの時間軸。
4. **P4 詳細パネル（閲覧のみ）** — 他人・確定済みの枠を選んだ状態。
5. **P5 詳細パネル（編集中）** — 自分の枠を編集している状態。複数枠。
6. **P6 複数選択中** — 下部に選択サマリーと操作バーが出ている状態。
7. **P7 状態バリエーション** — 読み込み中 / 0件 / 権限エラー / 通信失敗 / 保存中 / 保存失敗。

### スマートフォン（幅375px）

8. **M1 月ビュー** — 小さな月カレンダー＋選択日の詳細。
9. **M2 希望を入力（編集シート）** — 下からせり上がるシート。複数枠。
10. **M3 複数選択中** — 1行の要約バーと、展開した操作パネル。
11. **M4 絞り込みシート** — 属性・氏名検索・状態。

### 共通

12. **C1 ダイアログの型** — タイトル・本文・主/副ボタン・エラー表示の位置を決めた雛形。

## 2. 変えてほしいこと（段階2Aの目的）

### I-02 「見る」と「変える」を分ける

- 現在は、自分のセルをタップすると種別が循環して**即保存**される。これをやめる。
- **タップ＝詳細を開く**。編集は詳細内の「編集」から明示的に始める。
- 空欄のセルをタップしたら、日付入りの入力フォームを開く（いきなり保存しない）。
- **確定済み・他人の枠も詳細は読める**。編集できないことを、情報を薄くすること（不透明度を下げる）で表現しない。「編集できない理由」を短い文で書く。

### I-05 密度と優先順位

- 未回答セルは静かに（白＋点線、記号は「·」）。人数×日数ぶん並んでも視線を奪わない。
- 主操作は画面内に1つだけ強調する。ボタンの影・太字・枠線を整理する。
- **文字サイズの下限**: 通常の説明・入力 14〜16px、補足 12px。**時刻を8pxまで縮めない**（現状の週表示は8〜9px）。
- 人数が増えたら文字を縮めるのではなく、**要約・絞り込み・詳細表示**で対応する。月ビューは人数が多いとき「日別の人数・未回答・注意」の要約に切り替える案を出してほしい。
- 氏名は省略してよいが（現状は先頭2文字）、詳細では必ず全文を出す。

### I-07 ダイアログと操作可能性

- 共通の Dialog / Sheet: タイトル、初期フォーカス、Tab移動、Escapeで閉じる、閉じた後のフォーカス復帰。
- **送信の失敗は、操作した場所の中に出す**（主画面に出すとダイアログの裏に隠れる）。入力値は保持する。
- 矢印ボタンに「前の週」などの名前を付ける。時刻入力にラベルを付ける。
- 主なタップ対象は**44px**を目標（WCAG 2.2 の最小要件24×24pxとは別の、本プロジェクトの目標値）。
- 固定バーでフォーカス位置や保存ボタンが隠れないようにする。スマホは `safe-area-inset-bottom` を考慮。

## 3. 画面構成の案（これを土台に整えてほしい）

### PC

```text
[グループ名 ▼]                  [書き出し] [管理 ▼] [自分の名前 ▼]
[シフトを見る] [希望を入力] [確定・調整 ※権限あり]

[前へ] [2026年9月／9月14日〜20日] [次へ] [今日] [一覧｜月｜週]
[全員｜自分] [氏名検索] [属性 ▼] [状態 ▼] [条件解除]
表示対象 12人・希望のみ                         [凡例]

[必要な案内：未提出／確認待ち／変更あり。押すと対象へ]

[カレンダー／一覧                       ] [選択した日・人の詳細]
[                                      ] [時間枠・状態・履歴   ]
[                                      ] [編集／確定など       ]

複数選択時のみ：[3日・2人・5枠を選択] [操作] [選択解除]
```

- 上段＝所属と補助機能、次段＝作業目的、その下＝期間と表示条件。設定やログアウトを日常の入力と同じ重さで並べない。
- 上部の固定領域は期間・表示条件を中心にした最小限にする。ヘッダー全体を固定して表示面積を食わない。
- 詳細・編集は右パネルを基本とし、比較中のカレンダーを隠しすぎない。幅が足りない端末ではシートに切り替える。

### スマートフォン

```text
[グループ名 ▼]                             [メニュー]
[シフトを見る｜希望を入力｜確定・調整 ※権限あり]
[前へ] [2026年9月] [次へ] [今日]
[一覧｜月｜週]       [自分／全員] [絞り込み・適用数]

[次の自分のシフト／提出状況 ※必要時のみ]
[コンパクトな月カレンダー、または日付の選択帯]
[選択日の詳細：氏名・全時間枠・種別・状態]

編集中のみ下部シート：[日付・対象者] [入力欄] [保存]
複数選択中のみ下部バー：[選択数] [操作を開く] [解除]
```

- 単日の編集は「種別」「時間」「保存」を**縦**に配置する。6種類の種別と時刻入力を横1行に押し込まない。
- 属性チップを横に流し続けず、よく使う条件と適用中の条件だけ見せ、残りは絞り込みシートへ。
- 下部に常設ナビゲーションと大きな操作バーを重ねない。操作バーは1行の要約から展開する。

## 4. 守ってほしいデータ上の事実（デザインの前提）

ここを外すと実装できません。

| 事項 | 内容 |
|---|---|
| 勤務種別 | **管理者が定義する可変リスト**。既定は「出勤（○・青 #248DD4）」「リモート（R・青緑 #1F8A98）」「欠勤（×・コーラル #D9736F）」。最大6種程度を想定 |
| 予約語の種別 | 「却下」（橙 #E08A2E、×）。種別一覧には出ないが表示される |
| 状態 | 希望 / 確定 の2つ。加えて「不可（欠勤など出られない種別）」「未回答（データが無い）」という表示上の区別がある |
| 1日の枠数 | **1人1日あたり最大6枠**（グループ設定、既定4）。終日枠は1日1つまでで、時間枠とは併存しない |
| 時間 | 30分刻み。表示時間帯はグループ設定（既定 9:00〜20:00） |
| 週開始曜日 | 日曜 or 月曜（グループ設定） |
| 人数 | 1〜30人を想定。属性タグ（「社員」「スタダ」など）でOR絞り込みできる |

**状態の見分け方は、色だけに頼らず形でも区別する**（現行の仕組みを維持）。

| 状態 | 背景 | 枠線 | 記号 |
|---|---|---|---|
| 確定 | 種別色のベタ塗り | 同色・実線 | ✓ |
| 希望 | 種別色の淡色（白88%混合） | 種別色・**破線** 1.5px | 種別の記号（○ R など） |
| 不可・却下 | 種別色の淡色（白90%混合） | 淡い実線 1px | × |
| 未回答 | 白 | #E3E3E3・**点線** 1px | · |
| 選択中 | 背景を一段濃く | — | 右上に小さな ✓ バッジ |

## 5. 使う色・寸法（既存トークン。原則このまま使う）

`src/index.css` の `:root` に定義済み。**青系の基調は維持**し、装飾目的だけの全面配色変更はしない。

```
主色      --c-blue        #248DD4    押し込み影 --c-blue-deep #0863A0
淡い青    --c-blue-tint   #D1E9F9
青緑      --c-teal        #1F8A98
コーラル  --c-coral       #D9736F    線 #F0C7C7 / 背景 #FDF1F1
橙        --c-orange      #E08A2E
今日      --c-today       #F9E428    背景 #FFF6D6 / #FFFBEA / #FFFDF4
罫線      #E5E7EB → #EFF1F3 → #F1F3F5 → #F4F6F8（濃い順）
面        #fff / #FBFCFD / #FAFBFC / #F9FAFB   ページ背景 #F7F9FB
文字      #111827 / #374151 / #4B5563 / #6B7280 / #9CA3AF   未回答 #C8CDD2
```

- 書体: Noto Sans JP（400 / 700 のみ）。太字は 700。
- 角丸: 6px（rounded-md）を基本、カード・シートは 12px。
- ボタン: 高さ 34px（ナビ）/ 38px（操作）。押し込み表現 `box-shadow: 0 2px 0 0 #E3E3E3`（主ボタンは `#0863A0`）、押下時は 2px 沈めて影を消す。
- 既存の寸法トークン: 氏名列 132px（スマホ96px）、日付列 48px、行高 50px、週の1時間 32px、週の時刻列 44px、月のメンバーチップ 52px。**変更提案は歓迎だが、変えた寸法は明記すること。**

## 6. 受け入れ条件（デザイン確認の観点）

- **人数**: 1人 / 6人 / 12人 / 30人で破綻しない。30人のときの月ビューの見せ方を必ず示すこと。
- **氏名**: 2文字と6文字以上が混在しても崩れない。
- **種別**: 6種別＋却下が凡例と入力欄に収まる。
- **複数枠**: 同じ人の同じ日に 2枠・6枠あるとき、一覧・月・週のどれでも全部見える。
- **幅**: 375 / 390 / 768 / 1280px。横スクロールはテーブルの内側だけ。
- **状態**: 読み込み中・0件・権限エラー・通信失敗・保存中・保存失敗を、それぞれ区別して描く。
- **文字**: 補足も12px以上。時刻を8pxにしない。
- **色を外しても**（グレースケールでも）確定・希望・不可・未回答が区別できる。
