シフト管理アプリの使い方

URL は管理者から共有されたものを使ってください。


■ 初めて使うとき

1. 管理者から「招待リンク」と「招待コード」の2つを受け取る
2. 招待リンクを開き、「新規登録」タブでメールアドレスとパスワードを登録
3. 続く画面で招待コードを入力して「参加する」
4. メールアドレスの@より前の部分が、最初の表示名になる

2回目以降は「ログイン」タブでメールアドレスとパスワードを入れるだけです。

※ 招待リンクを使わずに開くと、参加時にグループIDの入力を求められます。
   リンクから開くのがいちばん確実です。


■ 表示名を変える

画面右上の自分の名前を押すと変更できます。


■ 3つの表示

右上の「一覧」「月」「週」で切り替えます。

・一覧: 縦にメンバー、横に日付が並ぶ表。全員の1か月分を一度に見られる基本画面
・月:  月のカレンダー。1日ごとにメンバー全員の状態が並ぶ
・週:  当月の全日を横につないだ時間帯表示(横スクロールあり)


■ セルの見かた

ベタ塗り + ✓   … 確定したシフト
薄い色 + 破線   … まだ希望の段階
薄い色 + 実線   … 出られない(不可・却下)
白の点線        … 未回答

色と記号は、その団体の設定によって変わります。
画面上部の凡例が、いま何色が何を意味するかを示しています。

セルが左右に分かれているときは、1日の中で時間帯ごとにシフトが分かれています。
横幅は実際の時間の長さに比例します。
（例: 左半分が濃い色、右半分が別の色 → 午前と午後で種別が違う）


■ 操作モード(右上のボタンで切り替え)

[通常モード](初期状態・どちらもOFF)
自分の行のセルだけタップできます。タップするたびに種別が1段階ずつ切り替わり
(未回答 → 1つ目の種別 → 2つ目の種別 → … → 出られない → 未回答)、
そのつど下部にパネルが開きます。パネルから直接ジャンプもできます。

・確定済みのセルはこのモードでは変更できません
・時間帯を設定したセルはタップで切り替わりません(誤って時間が消えるのを防ぐため)。
  変更はパネルから行ってください

[複数選択モード]
自分の複数の日をまとめて選び、下部パネルで一括登録・一括で未回答に戻す・
時間帯の一括設定ができます。

[確定選択モード] ※ 管理者とリーダーだけに表示されます
誰の行のセルでも選べます(未回答のセルは対象外)。下部パネルから

  ・確定にする  … 希望を確定シフトにする
  ・確定を取消  … 確定を希望に戻す
  ・却下        … 希望を却下する

一般メンバーにはこのボタンは表示されません。


■ 1日を時間で分ける

1つの日に複数のシフト枠を入れられます。

1. 自分のセルをタップして選ぶ
2. 下部パネルの「時間で分ける」を押す
3. 「＋枠を追加」で枠を増やし、それぞれ種別と開始・終了時刻を設定
4. 「保存」

・「終日」にチェックを入れると時刻の指定を外せます
・時間帯が重なっているとエラーになります
・終日の枠と時間指定の枠は同時に登録できません
・1日に入れられる枠の数は、団体の設定によります(既定は4つまで)


■ よくある操作

・希望日をまとめて登録したい
  → 「複数選択」→ 自分の日を選ぶ → パネルの種別ボタン

・誰かの希望を確定したい ※管理者・リーダーのみ
  → 「確定選択」→ そのセルを選ぶ → 「確定にする」

・午前は出社、午後は在宅にしたい
  → セルを選ぶ → 「時間で分ける」→ 枠を2つ作って時刻と種別を設定

・ログアウト
  → 画面右上の「ログアウト」


■ 管理者の方へ

ヘッダーに次のボタンが追加で表示されます。

・メンバー   … ロールの変更、表示名の変更、退会処理(在籍のチェックを外す)
・設定       … 招待リンクのコピー、招待コード、表示時間帯、週の開始曜日、1日の枠上限、シフト種別

シフト種別は、団体に合わせて名前・色・記号を変えられます(最大6種類)。
種別を削除しても、その種別で登録済みのシフトは残ります。
